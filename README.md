# Math-Puzzle-Printables-Generator
Generates printable math puzzles of a certain kind

This is just a small tool I had thrown together by Claude AI, because I thought it was a neat thing and read some people had a use for this.
Just download it and open the index.html. It will open the puzzle generator in your browser.
There are probably bugs somewhere, so let me know if you care to improve this.
